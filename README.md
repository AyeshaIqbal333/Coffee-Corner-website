☕ Coffee Corner Website

Coffee Corner is a simple and attractive coffee shop website created to showcase a café's menu and provide visitors with a pleasant browsing experience. It is developed using HTML, CSS, and JavaScript, with a clear and dark mode feature.

✨ Features

- Attractive coffee shop website design.
- Clear and dark mode functionality.
- Responsive and user-friendly layout.
- Coffee shop image and content.

🛠️ Technologies Used

- HTML – Website structure.
- CSS – Styling and layout.
- JavaScript – Interactive functionality.

🚀 How to Run the Project

You can view the live project here: [Add GitHub Pages Link Here]

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the "index.html" file.
4. The website will open in your default browser.

Note: For the best experience, use a modern browser such as Google Chrome or Mozilla Firefox.

📁 Project Files

- "index.html" – Main webpage.
- "styles.css" – Website styling.
- "script.js" – JavaScript functionality.
- "cafe.png" – Coffee shop image.
